# Coding Practice – C++ & Python

This repository contains a collection of small practice problems written in both C++ and Python.  
These exercises helped me review basic programming concepts such as loops, conditionals, strings, arrays/lists, simple algorithms, and general problem-solving.

The goal of this repo is to track my practice work and reinforce my fundamentals while preparing for early-career software engineering roles.
